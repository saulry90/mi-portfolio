# Portfolio Personal – Saul Roldan

Este proyecto es mi portfolio personal, desarrollado con **HTML, CSS y JavaScript** (base Vite).  
Su objetivo es mostrar mis habilidades como maquetador web y desarrollador frontend.

---

## 🧩 Tecnologías
- [Vite](https://vitejs.dev/)
- HTML5 / CSS3 / JavaScript (Vanilla)
- Node + npm (para el entorno de desarrollo)

---

## 🚀 Scripts disponibles

En la raíz del proyecto puedes ejecutar:

```bash
npm install       # Instala dependencias
npm run dev       # Inicia el servidor de desarrollo
npm run build     # Genera build de producción
```

---

## Deploy

**Plataforma:** Netlify  
**URL:** [portfolio-saul.netlify.app](https://portfolio-saul.netlify.app)  
**Configuración:** `netlify.toml` en la raíz del repo  
**Flujo:** Push a `master` → deploy automático
